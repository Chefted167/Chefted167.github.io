# SONARA MUSIC Website

A modern, responsive static website for SONARA MUSIC — Music Distribution & Artist Services.

## Files
- index.html — main website
- style.css — styling and responsive layout
- script.js — mobile navigation, year and demo contact form

## Before going live
1. Replace the placeholder contact email in `index.html`.
2. Replace the `#` social links with your official profiles.
3. Connect the contact form to an email/form service if you want submissions to arrive somewhere.
4. Upload all three files to your GitHub repository. Keep them in the same folder.
5. Make sure `index.html` is the repository's published entry page.

The website is intentionally written as a static site, so it works with GitHub Pages without a server.
